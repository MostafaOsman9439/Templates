# Template Three - Personal Hobby & Anime World Portfolio

An advanced, fully responsive, and modern multi-section landing page built from scratch. This project is inspired by the famous **Elzero Web School** Challenge (Template 3), customized and tailored to showcase my world—including my favorite Mangas, Anime/Game characters, friends, and web development skills.

**Live Demo:** [View Project Live](https://mostafaosman9439.github.io/Templates/)

---

## Features & Sections

This landing page is packed with dynamic CSS layouts and modern UI components:
* **Hero Section:** A welcoming entrance introducing my passion, books, games, and events.
* **Mangas & Gallery:** A beautifully structured grid displaying favorite series (Oshi no Ko, Frieren, JJK, etc.) with clean hover effects.
* **Features Section:** Highlighting core principles—Quality, Time, and Passion.
* **Team / Friends:** A dedicated section displaying my friends and fellow full-stack developers.
* **Anime & Game Characters:** Custom card layouts featuring top characters from favorite anime and gacha games (Wuthering Waves/Genshin Impact like Yinlin, Changli, Shorekeeper).
* **Skills Dashboard:** A dynamic visual showcase of my current frontend progress (HTML, CSS, and growing JavaScript skills).
* **Pricing Plans & Latest Events:** Clean, professional tables and structures for events and discounts.
* **Video Gallery & Advanced Footer:** A video playlist UI design and a detailed multi-column footer ending with a special thanks to Elzero Web School.

---

## Tech Stack Used

* **HTML5:** Semantic layout structure (`<section>`, `<article>`, `<nav>`, `<footer>`).
* **CSS3:** Advanced layout techniques, custom typography, animations, dynamic hover states, and **Glassmorphic/Blur** overlay effects.
* **Responsive Design:** Fully optimized to look stunning on Desktops, Tablets, and Mobile screens.
